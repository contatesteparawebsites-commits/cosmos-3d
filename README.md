# 🌌 COSMOS 3D

Um explorador espacial interativo para navegar pelo universo diretamente no navegador.

## 🚀 Projeto

O COSMOS 3D foi criado para ser uma experiência visual e interativa de exploração espacial, com foco em uma interface moderna e uma experiência simples de usar.

## 🪐 Recursos planejados

- Universo 3D interativo
- Sistema solar explorável
- Planetas e luas
- Estrelas e objetos espaciais
- Câmera livre com zoom e órbita
- Informações sobre objetos celestes
- Interface futurista
- Experiência em um único HTML

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript
- Three.js

## 📄 Licença

Este projeto é experimental e destinado a estudo e exploração no navegador.
